# 变更记录

本文件最多保留 3 条，超了删最早的那条。

## 0.1.1 — 2026-10-22

挂载方式修正：必须挂进模式自己的压缩组，不能挂在配置档根层。压缩服务被隔离在模式内部，
根层插件拿不到它，会静默失联且不报错。README 补充了完整步骤、原因和这个限制。

## 0.1.0 — 2026-10-24

首个版本。给模型一个 `compact` 工具，只登记任务，等会话空闲（`agent/status` 为 `idle`）
再调 `ctx.compaction.compactNow` 执行，复用宿主现有压缩后端。

- 时机清单写进工具描述，不改系统提示。
- 失败最多重试 3 次；没有可压缩历史时不重试。
- 冒烟测试 `test/smoke.mjs` 覆盖：只登记不立即压、仅在空闲执行、不重复执行、
  失败重试上限、未登记会话不受影响。
